Cookbook
========

Practical, cross-tool integration recipes for the Extended Matrix
ecosystem. Each page in this tree walks through *how a real workflow
crosses the boundary* between Extended Matrix and another tool —
PyArchInit, BlenderGIS, remote-sensing pipelines, CAD/GIS importers,
Zenodo publication, legacy-graph migration, and so on.

These recipes complement the formal language reference (this manual)
and the per-tool manuals (EM Tools, 3DSC, Heriverse) by describing
the *boundary conditions*: where data enters and leaves the
Extended Matrix world, which fields map to which, and what
round-trip guarantees are preserved.
