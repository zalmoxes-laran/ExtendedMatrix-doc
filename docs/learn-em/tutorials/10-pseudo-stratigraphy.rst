Overview
--------

Geophysical and remote sensing data can be integrated into EM as pseudo-stratigraphic units — hypothetical nodes that represent detected features before physical excavation. When excavated, pseudo-SUs are equalized to real SUs. This supports open, evolving datasets.

.. figure:: /_static/screenshots/clip_10/0001_geophysical_data_blender.jpg
   :alt: Geophysical survey data imported and visualised in the Blender 3D scene.
   :width: 90%

   Geophysical survey data imported and visualised in the Blender 3D scene.

Key Concepts
------------

- Pseudo-SUs represent detected features from non-invasive surveys.
- Geophysical data (GPR, magnetometry) can be visualised directly in Blender.
- Equalization: pseudo-SU → real SU when physically excavated and confirmed.
- EM supports open datasets that evolve over time — data is never final.
