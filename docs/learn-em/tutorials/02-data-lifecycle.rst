Overview
--------

The four-phase EM workflow: creating data, managing data, enriching data, and exporting data. EM can start from various sources — historical photos, drawings, 3D surveys — but 3D models are the ideal starting point.

.. figure:: /_static/screenshots/clip_02/0001_four_phase_workflow.jpg
   :alt: The four-phase EM data lifecycle: Create, Manage, Enrich, Export.
   :width: 90%

   The four-phase EM data lifecycle: Create, Manage, Enrich, Export.

Key Concepts
------------

- The four phases: Create → Manage → Enrich → Export.
- EM works with any source: historical photos, drawings, geophysical data, or 3D surveys.
- 3D models are the ideal starting point because they are the most information-rich.
- A playground dataset is available to practise with each workflow step.
