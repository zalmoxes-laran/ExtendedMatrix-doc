What is a Time Branch ?
-----------------------

 A time branch represents a set of nodes grouped by a `TimeBranchNodeGroup`, which is provided within the palette in the yED system for simplicity. Each time branch is visually characterized by a green header and indicates a potential temporal development of stratigraphic units, including their unique properties and the documents used to reconstruct them. 

Each time branch has a defined start and end, allowing it to span across multiple epochs. Two time branches can be mutually exclusive, with only one applied at a time, achieved by connecting them with a dashed-line connector.
